01 — 初衷

教务的事，
在手机上顺手办好。

上课前查一眼教室，出分后看看成绩，选课时翻翻课程信息。这些事很日常，也值得有一个更方便的入口。

「华师教务」是一款面向华南师范大学在校学生的 Android 非官方教务辅助应用。它把课表、成绩、考试安排、通知公告和选课信息集中起来，让移动端的浏览与操作更清晰。

用 Kotlin · Jetpack Compose · Material 3 构建，专注于你真正会用到的校园教务场景。

为日常提供便利。重要教务信息，始终以学校教务系统为准。
02 — 课表

下一节上什么，
一眼就知道。

按周展开课程安排，自动定位当前周。左右切换周次，点开课程，教师、地点、节次、校区、学分和上课周次都在里面。

  • 按你的习惯设置。开学日期、学期总周数、上课时间和学期识别方式，都可以调整。
  • 课表也有自己的颜色。多套内置课程配色，一键切换，让每周的安排看着更舒服。
  • 带走一份课表。支持导出当前学期的 PDF 课表，也能直接查看学校校历。

03 — 成绩与考试

每一份努力，
都看得更清楚。

按学期查看历史成绩，不只看一个总分。点开成绩详情，平时分、期末分、综合分和各项占比，一起了解。

成绩，分项看

查看已出分课程、第二类课程成绩，支持导出成绩表格。需要正式材料时，可以申请电子成绩单、电子证明，预览并下载 PDF。

考试，提前知

查询本学期及历史学期的考试安排，确认时间、地点、座位号和校区。支持导出考试表格，方便留存。

04 — 选课与学业

这一学期怎么选，
整个学业走到哪。

选课开放时，按课程类型浏览可选课程，查看课程详情与容量，提交选课请求，再到已选列表中确认。

  • 喜欢的课程，先收藏。复制课程信息即可添加到收藏列表，收藏内容也支持通过复制粘贴跨设备分享。
  • 培养方案，逐层展开。查看学业概览、学分进度和培养方案，展开对应模块，按需加载课程列表。
  • 已修、在修、还差什么。区分已修、在修、未修、未过和课程替代状态，查看课程成绩、绩点及学分。
  • 筛除结果，也有入口。查询被筛除的课程，查看教学班、教师、上课时间和地点等详情。
05 — 校园日常

不止查课表。
还有学习里的大小事。

教务通知、下发文件、站内消息，在同一个入口查看。消息分为待阅与已阅，部分通知与文件支持附件下载。

常用的事，集中处理

查看校历、管理个人信息、完成学生评价。评价支持填写评语、保存草稿与提交，已提交内容可查看。

需要时，问问 AI 助手

支持多会话、流式回复、Markdown 和公式显示。助手与教务功能分离，入口按开发者授权显示。

06 — 使用之前

方便之外，

这是一个非官方工具。应用不承担学校官方教务服务职责，仅供学习与便利使用。请确认自己具备合法访问学校教务系统的权限，并遵守学校规定。

应用包含资格验证与设备标识相关能力，部分功能受版本或授权状态影响。使用前请阅读仓库说明，在可信设备上登录和使用。

08 — 常见问题

你可能还想知道。

这是学校官方开发的 App 吗？

这是面向华南师范大学在校学生的非官方教务辅助工具，与学校官方客户端无关。所有重要教务事项均以学校教务系统及官方通知为准。

iPhone 或电脑可以安装吗？

目前仅提供 Android APK 安装包，要求 Android 7.0 或更高版本，没有 iOS 或桌面版本。这个网页用于介绍和下载应用，本身不能查询教务数据。

下载以后，应该怎么安装？

前往 GitHub Releases，下载发布版本中的 .apk 文件，在 Android 手机上打开安装。若系统提示，请为你使用的浏览器或文件管理器开启「安装未知应用」权限。请核对安装包来自 AlgoZZi/ScnuJwxt-APK 仓库。

为什么有些功能没有显示？

部分功能会随应用版本、教务系统开放时间和授权状态变化。AI 助手入口按开发者授权显示，选课功能需要在学校开放的时间内使用。

数据不更新，或者遇到了问题怎么办？

先尝试刷新或重新登录，检查账号与网络状态。如果仍然有问题，可以通过应用内「我的 → 反馈」提交问题和建议。

可以在 GitHub 找到 App 源码吗？

目前该仓库用于项目介绍及 APK 发布，不公开 App 源码。可以在 Releases 获取安装包，或阅读 README 了解完整功能与使用说明。
